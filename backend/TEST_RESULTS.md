覆盖：

- Bearer 会话、PBKDF2 密码、会话退出和登录节流。
- 工单、运行、订单、知识库、审批及审计的租户隔离。
- 真实 LangGraph 五节点执行、逐步持久化轨迹和运行期间查询。
- BM25 引文、超期订单、低证据拒答和注入关键词拒答。
- 非审批角色拒绝、自批拒绝、批准/驳回终态。
- 退款同键五线程幂等；不同审批并发时的订单余额和租户预算限制。
- 恶意模型金额、伪造引文、回答中额外跨租户引文、浮点/布尔金额拒绝。
- 政策版本变化使旧审批失效；历史轨迹回放不产生新审计或退款。
- 正常重启保留数据；中断运行标记失败且保留步骤。
- OpenAI-compatible HTTP 请求和结构化响应解析（MockTransport）。
- 模型超时/异常的失败状态与脱敏错误、请求体大小和未知字段限制。

这是合成数据上的工程回归验证。真实模型接口使用 mock 验证协议，没有调用真实模型，不是模型效果评测、性能压测或生产安全审计。数据库退款均为本地模拟账本。

独立审查另在临时数据库验证：回答中追加其他租户引用会拒答；退款审计写入抛异常时订单余额、退款账本、审批与幂等记录全部回滚；真实 provider 的 mock 非法 JSON、未知动作和 HTTP 429 都保持零审批/退款且不会回显供应商敏感错误内容。这些探针不计入以上 pytest 测试数。
